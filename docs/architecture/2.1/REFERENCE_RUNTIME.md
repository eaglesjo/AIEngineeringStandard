# v2.1 Reference Runtime\n\nThe reference runtime in core/runtime/v2_1/ makes the canonical multi-agent semantics executable without binding the standard to an LLM provider, orchestration framework, MCP implementation, or IDE.\n\nIt demonstrates:\n\nAgent + Role → Agent Contract → Work Unit → Evidence → Handoff → Evaluation → Acceptance\n\nEffective permissions are the intersection of the registered agent permission ceiling and the role allowed permissions. Handoffs and evaluations may reference only registered evidence.\n\nRetry creates a new Work Unit attempt with parent_id, preserves an explicit retry reason, and carries failure_evidence_refs from the failed Work Unit. The failed attempt is never overwritten.\n\nThis is a deterministic conformance runtime, not a production scheduler.
