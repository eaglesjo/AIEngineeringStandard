# MCP Standard Layer

MCP is an integration boundary, not an implicit trust boundary.

AIEngineeringStandard 2.0 will define vendor-neutral requirements for:

- server registration;
- tool/resource/prompt access;
- permission and approval boundaries;
- secret handling;
- provenance and source verification;
- version pinning where practical;
- timeout/failure behavior;
- audit and evidence requirements.

M1 establishes the contract boundary only. Concrete MCP adapters and security validators arrive in later milestones.
