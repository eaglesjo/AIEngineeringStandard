# Agent Plugin Standard Layer

AIEngineeringStandard 2.0 targets the published Agent Plugins 1.0.0 specification as its portable packaging baseline.

The normative layer covers:

- `plugin.json` metadata;
- portable `skills/` content;
- optional `mcp.json` configuration;
- explicit vendor extension namespaces.

External Plugin specification drafts are tracked separately and are not hard dependencies of the 2.0.0 baseline.
